# User Dashboard

A modern and responsive **User Management Dashboard** built as part of an internship project. The dashboard provides an intuitive interface for managing users, searching records, and viewing user information with a clean, enterprise-inspired design.

## ✨ Features

* Modern and clean user management interface
* Responsive dashboard layout
* Dynamic user data fetched from an external API
* Search users by name or username
* Sidebar navigation for easy accessibility
* Professional table-based user listing
* Reusable UI components
* Optimized spacing and typography

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Tailwind CSS
* JSONPlaceholder API

## 🎨 Design Process

The dashboard design began with **paper wireframes**, allowing the overall layout, navigation flow, and component placement to be planned before development.

As the **UI/UX Designer**, my responsibility was to transform the wireframe into a polished and responsive interface by:

* Designing the overall user experience
* Creating the visual hierarchy
* Implementing the complete CSS styling
* Improving spacing, typography, and color consistency
* Ensuring responsiveness across different screen sizes

The application structure and interactive functionality, including HTML markup, JavaScript logic, API integration, and search functionality, were implemented by **@shivamani-abbili**.

This collaborative workflow closely followed a real-world product development process, where design and frontend development responsibilities were handled independently.
